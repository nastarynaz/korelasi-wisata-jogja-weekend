# Menggunakan proyek versi wisata

1. Buka https://colab.research.google.com/drive/1DvzX-nuuoy03t1u9p99IQd4ZRJotZYlm . Tutup tab lama bila masih menampilkan topik cuaca.
2. Notebook sudah berisi sepuluh grafik. Untuk menghitung ulang, pilih Runtime → Run all. Data dari Sheets publik tanpa login.
3. Baca penjelasan sebelum setiap kode dan hasil sesudahnya. Klik kanan gambar untuk menyimpan satu PNG; salinan PNG/PDF tersedia di panel Files setelah dijalankan. Tidak ada unduhan ZIP otomatis.
4. Simpan salinan notebook beserta output ke Drive. Notebook menyimpan kode/output, sedangkan file runtime sementara dapat hilang.
5. Kode versi terbaru tersedia dalam paket kode di folder Drive proyek. Unggah isi paket ke repositori GitHub kelompok dan periksa akses dosen. Tidak perlu mengumpulkan ZIP sebagai keluaran analisis.
6. Gunakan video topik wisata lima menit, bukan video arsip hubungan hujan. Unggah ke eLOK sesuai instruksi tugas; sertakan URL GitHub dan daftar lima anggota bila diminta. Pengiriman GitHub/eLOK belum dilakukan oleh agen.

Sumber destinasi dan lokasi sekarang berada pada tab Destinasi Terverifikasi dan Lokasi Wilayah dalam spreadsheet referensi publik. Tab cuaca lama dipertahankan sebagai arsip dan tidak dibaca notebook versi wisata.
